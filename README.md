A one-line joke about working beside AI coding agents, for [make.fun's "The joke about the demo" bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

## How it works

`main.ts` (Node 22) writes a single one-line joke to `/output/entry.txt` (UTF-8, 1-280 characters). An AI judge compares entries two at a time and ranks them by win rate.

## Run

```
node main.ts
```

Writes `/output/entry.txt`. No network.
